## Observing & Data Reduction Tutorials

- [ALMA Data Reduction](casa_almadr_2026v2.pdf) \
CASA tutorial for ALMA data processing, from data retrieval to science-ready products, and illustrated with mock ALMA data (2026).

- [Magellan Observing Notes](magellan_obsnotes_2025v1.pdf) \
Observing notes to help prepare optical and near-IR spectroscopy of galaxies using Magellan-Clay/LDSS3 and Magellan-Baade/FIRE, including the associated proposal, LDSS3 mask files, observing plans, and logs for the cluster lens MACSJ2243–0935 (2025).

- [LENSTOOL Cheat Sheet](lenstool_cheatsheet_2026v1.pdf) \
A short list of useful commands for new LENSTOOL users, covering general usage and ray-traced source-plane reconstruction.
